プライバシーポリシー

Android アプリ「血圧手帳」（以下「本アプリ」）における、 利用者の情報の取り扱いについて定めます。

アプリ名 血圧手帳　/　パッケージ名 com.job17.bloodpressure
制定日 2026年8月29日　/　最終改定 2026年8月29日　/　第 2.0 版

はじめに、要点だけ。

  • 入力された血圧・脈拍・体重・メモは、お使いの端末の中だけに保存されます。 開発者を含め、誰にも送信されません。
  • 本アプリは画面下部に広告を表示します。 広告の配信のため、Google（AdMob）が広告 ID などを取得します。
  • 広告に、あなたの測定した記録を渡すことはありません。
  • アカウント登録は不要です。

1収集する情報

本アプリ自身は、利用者の情報を収集しません。 入力された血圧・脈拍・体重・メモが開発者に送られることはなく、 開発者が利用者の記録を見ることはできません。

利用状況の解析（アクセス解析・クラッシュレポートなどを含む）も行いません。 本アプリには、そうした機能を持つ外部のソフトウェア部品を組み込んでいません。

ただし、広告の配信のために組み込んでいる Google のソフトウェア部品 （Google Mobile Ads SDK）が、広告を出すために必要な情報を取得します。 詳しくは次の項をご覧ください。

2端末内に保存される情報

利用者が入力した次の情報は、端末内のアプリ専用領域に保存されます。 この領域は他のアプリから読み取れません。

保存されるもの内容
血圧・脈拍最高血圧、最低血圧、脈拍、測定日、測定機会（朝・夕）、測定回、測定時刻
体重1日1回の体重
メモ利用者が自由に入力した文字（100文字まで）
設定1機会あたりの測定回数、表示の切り替え、リマインダーの時刻など

これらは端末の外へ送信されません。クラウドにも保存されません。 端末のバックアップ機能によって外部へ複製されることもありません （マニフェストで allowBackup="false" を指定しています）。

本アプリをアンインストールすると、これらの記録も一緒に削除されます。 削除された記録を復元する手段はありません。 機種変更などで記録を引き継ぐ場合は、アプリの機能で CSV ファイルとして 書き出したうえで、新しい端末で読み込んでください。

3アプリが求める権限

本アプリが自ら宣言している権限は次の4つです。

権限使いみち
INTERNET 広告を受け取るために使います。 これ以外の目的では通信しません。
ACCESS_NETWORK_STATE 通信できる状態かどうかを広告の配信側が確認するために使います。
POST_NOTIFICATIONS 測定リマインダーの通知を出すために使います。 リマインダー機能を使わない場合、許可は不要です。
RECEIVE_BOOT_COMPLETED 端末を再起動したあとも、設定したリマインダーの時刻を保つために使います。

このほかに、広告を配信する Google Mobile Ads SDK が、広告 ID の参照や 広告の計測のための権限（AD_ID、 ACCESS_ADSERVICES_*、 WAKE_LOCK、 FOREGROUND_SERVICE）を自動的に追加します。 これらは SDK が広告のために使うもので、本アプリが独自に使うことはありません。

通信は広告のためだけに行います。本アプリが独自のサーバーへ接続することはなく、 入力された記録を送る処理は実装されていません。

位置情報、連絡先、カメラ、マイク、写真にはいっさいアクセスしません。

4ファイルの書き出しについて

利用者の操作によって、記録を PDF または CSV として書き出せます。 保存先は、書き出しのたびに利用者自身が選びます （Android の標準の保存画面を使います）。

書き出したファイルには血圧などの測定値が含まれます。 端末の共有フォルダーに置かれるため、他のアプリから読める場所に なる場合があります。第三者に渡すときは中身をご確認ください。 書き出したあとのファイルの管理は、利用者の責任となります。

5広告について

本アプリは、Google の広告配信サービス「AdMob」を利用して、 画面の下部にバナー広告を表示します。 表示するのはバナー広告だけです。全画面広告、動画広告、 起動時の広告は使用しません。また、血圧を入力する画面には 広告を表示しません。

広告を配信するため、Google（および Google の広告配信パートナー）が 次のような情報を取得することがあります。 これは Google Mobile Ads SDK が行うもので、本アプリが渡すものではありません。

  • 広告 ID（Android 広告 ID）
  • 端末の種類、OS のバージョン、画面の大きさ、言語などの情報
  • IP アドレス、おおまかな地域
  • 広告の表示・クリックに関する記録

本アプリが広告に渡す情報はありません。 あなたが入力した血圧・脈拍・体重・メモ、およびそれらから計算した平均や グラフの内容が、広告のために使われることはありません。

Google による情報の取り扱いについては、次をご覧ください。

  • 広告 — ポリシーと規約（Google）
  • プライバシー ポリシー（Google）

広告のもとになる広告 ID は、端末の設定から削除・リセットできます。 Android の［設定］→［プライバシー］→［広告］（機種により場所が異なります） から、広告 ID の削除や、広告のカスタマイズの無効化ができます。

広告以外の目的で、第三者へ情報を提供することはありません。 解析事業者への提供も行いません。 本アプリにアプリ内課金の機能はありません。

6子どもの利用について

本アプリは、家庭で測定した血圧を記録するためのものであり、 子ども向けに設計されたアプリではありません。 主に成人の利用を想定しています。

本アプリ自身が、年齢を含む利用者の情報を集めることはありません。

7医療上の位置づけ

本アプリは記録と表示のためのものであり、病気の診断を行いません。 表示される血圧の区分は、日本高血圧学会 高血圧治療ガイドライン 2019 の 家庭血圧の分類にもとづく参考情報です。 また、低い側の血圧（低血圧）の判定は行いません。

1回の測定値だけで健康状態を判断することはできません。 気になる値が続く場合は医師にご相談ください。

8本ポリシーの変更

本アプリの機能を追加・変更した場合、それに合わせて本ポリシーを 改定することがあります。改定したときは、このページの 「最終改定」の日付と版数を更新します。

情報の取り扱いに関わる変更（たとえば広告の表示や、外部との通信を 伴う機能の追加）を行う場合は、その内容を本ポリシーに明記したうえで、 アプリの更新と合わせてお知らせします。

9お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせは、 Google Play ストアの本アプリのページに記載の連絡先までご連絡ください。
